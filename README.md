# Implementation of a Spread Spectrum Communication System

This repository contains the code, MATLAB models, theoretical report and
software-defined radio (SDR) work for a project on implementing a communication
system based on spread spectrum.

## Repository structure

```
.
├── Codes/
├── MATLAB_Modelling/
├── Theoretical_Report
└── SDR/
```

### `Codes/`

The codes used in the project. Each code is explained in detail, and the titles
are clear.

### `MATLAB_Modelling/`

The MATLAB modelling of the two systems studied in this project.

### `Theoretical_Report`

The theoretical report of the project.

### `SDR/`

The software-defined radio (SDR) part of the project.
